# MOSS-Image 桌面版 · 本地使用说明

> 把「MOSS-Image 本地工作台」（Gradio 网页）封装成 macOS 桌面 App 的使用手册。
> 适用机型：Apple Silicon（M 系列）Mac；本机已在 `ppt-sum/.moss/` 中装好 MOSS-Image + Gradio 服务。

---

## 1. 文件清单

| 文件 | 用途 |
| --- | --- |
| `MOSS-Image_0.1.0_aarch64.dmg` | 安装包，内含 `MOSS-Image.app` |
| `启动 MOSS-Image.command` | 一键脚本：先拉起本地服务，再打开 App |
| `MOSS-Image.icns` | 应用图标（备用） |
| `使用说明.md` / `使用说明.docx` | 本手册 |

- 图标：彩色狸花猫（方案 B，蜷缩环猫，扁平矢量）
App 参数：bundle id `com.moss.image`，版本 `0.1.0`，窗口默认 1280×860，ad-hoc 签名（**未做 Apple 公证**）。

---

## 2. 它是什么

- **外壳**：Pake（Tauri 2 + Rust）封装的 WebView 窗口，地址固定为 `http://127.0.0.1:7860`。
- **内核**：本机 `.moss/` 里的 MOSS-Image（OpenMOSS 5B 文生图 DiT，Apple Silicon 上的 MLX 移植版，compact 档）+ Gradio 工作台。
- **关系**：App 只是“窗口”；生成能力来自本地 Python 服务。**服务没启动时，App 会白屏/提示连接失败**——这是设计使然，用“启动脚本”即可避免。

---

## 3. 安装（只需一次）

1. 双击 `MOSS-Image_0.1.0_aarch64.dmg`，把 **MOSS-Image.app** 拖到「应用程序 / Applications」。
2. 由于未公证，首次打开可能被 Gatekeeper 拦截：
   - 推荐：在「应用程序」里**右键 → 打开**，再点“打开”；
   - 或终端执行一次：`xattr -dr com.apple.quarantine /Applications/MOSS-Image.app`
3. 之后即可正常双击启动。

> 若系统提示“无法验证开发者”，属于未公证的正常现象，不是文件损坏。

---

## 4. 日常启动（推荐用脚本）

双击 **`启动 MOSS-Image.command`**（首次可能被拦：右键 → 打开）。脚本会：

1. 检查 `127.0.0.1:7860` 是否已有服务；
2. 没有就用 `.moss/ui/start.sh` 启动，并最多等待 90 秒；
3. 服务就绪后打开 `MOSS-Image.app`。

**手动方式**（等价）：

```bash
# 终端 1：启动工作台服务
cd ~/Desktop/ppt-sum
.moss/ui/start.sh

# 终端 2 或直接双击 App
open -a /Applications/MOSS-Image.app
```

停止服务：`pkill -f ".moss/ui/app.py"`

## 5. 界面怎么用

| 区域 | 说明 |
| --- | --- |
| 提示词 | 支持中英混排、`\n` 换行；可直接写要渲染在画面里的文字 |
| 反向提示词 | 默认已带质量/乱码抑制词，一般不用改 |
| 画布尺寸 | 16:9 1280×720（PPT 封面/横版）、1:1 1024、4:3、3:4 |
| 随机种子 | `42` 可复现；`-1` 每次随机 |
| 步数 / CFG | 官方默认 50 步 + CFG 3；勾 turbo 时步数被忽略 |
| turbo | 15 次网络前向，速度快数倍；文字仍基本保持 |
| 常驻显存 | 勾选后组件不释放，更快但内存约 11 GB（16 GB 机器慎用） |
| Layout JSON | 粘贴精确排版 JSON（`summary.caption` + `items[].bbox`），自动校验越界 |
| 输出 | 生成结果可预览、下载 PNG 与参数 JSON；文件落在 `ppt-sum/moss-ui/out/` |

**耗时参考（本机 M4 / 16 GB）**：1280×720 turbo 约 5–6 分钟；官方 50 步约 12–15 分钟。生成期间页面显示去噪进度与预计剩余时间，请求串行排队。

## 6. Layout JSON 速记

```json
{
  "summary": {"caption": "画面整体描述（英文更稳）"},
  "items": [
    {"label": "text", "text": "要渲染的文字", "bbox": [-240, -490, -92, 490]}
  ],
  "bbox_coord_space": "abs_centralized",
  "bbox_format": "yxyx"
}
```

- `bbox = [y_min, x_min, y_max, x_max]`，**画布中心为原点**；1280×720 画布 x: -640..640，y: -360..360。
- 文字越大越稳；20px 级别的生僻字容易出错，可在提示词里换同义表述规避。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| App 白屏 / 一直转圈 | 服务没起：跑 `启动 MOSS-Image.command`，或看 `.moss/logs/ui.log` |
| 端口 7860 被占用 | `lsof -nP -iTCP:7860 -sTCP:LISTEN` 找到进程后 `kill <PID>` |
| 生成很慢 | 关闭其他吃内存的 App；确认勾了 turbo；swap 满时速度会掉一半以上 |
| 内存告警 / 系统卡 | 不要勾“常驻显存”；compact 档峰值约 7.4 GB，另需约 1 GB 系统余量 |
| 首次打开被系统拦截 | 右键 → 打开；或 `xattr -dr com.apple.quarantine /Applications/MOSS-Image.app` |
| 模型文件缺失 | 确认 `ppt-sum/.moss/models/MOSS-Image-SFT-MLX-compact` 存在（12.08 GB） |
| 想改提示词模板 | 改 `.moss/ui/app.py` 后重启服务 |

## 8. 数据与隐私

- 全部推理在**本机运行**；除首次从 HuggingFace 镜像下载权重外，不向外部上传提示词或图片。
- 图片与参数 JSON 只存本地 `moss-ui/out/`。
- 工作台 HTTP 服务仅监听 `127.0.0.1`，局域网其他设备访问不到。

## 9. 卸载

```bash
rm -rf /Applications/MOSS-Image.app
# 如不再使用工作台（谨慎）：rm -rf ~/Desktop/ppt-sum/.moss
```

卸载 App 不会删除模型；`.moss/` 同时被 PPT 出图脚本共用。

## 10. 技术信息（复现/升级用）

- 封装工具：`pake-cli 3.18.0`（Tauri 2，target `aarch64-apple-darwin`）
- 工具链：项目内 rustup（`moss-app/toolchain/`，cargo 1.99.1），crates 走 rsproxy 镜像
- 构建命令：
  ```bash
  cd ~/Desktop/ppt-sum/moss-app
  export CARGO_HOME="$PWD/toolchain/cargo" RUSTUP_HOME="$PWD/toolchain/rustup" PATH="$PWD/toolchain/cargo/bin:$PATH"
  npx pake "http://127.0.0.1:7860" --name "MOSS-Image" --identifier "com.moss.image" \
    --icon icon.icns --width 1280 --height 860 --title "MOSS-Image 工作台" \
    --app-version 0.1.0 --targets dmg
  ```
  Tauri 的 dmg 步骤若被沙箱拦住，可手动打包（见 `moss-app/MOSS-Image_0.1.0_aarch64.dmg` 的生成方式）。
- 升级：改 App 名/URL/图标后重新构建；模型与工作台升级只影响 `.moss/`，App 无需重建。
